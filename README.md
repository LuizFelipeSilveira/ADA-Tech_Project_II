# 📊 Análise de Dados da NBA: Foco em LeBron James 📊 

## 📌 Introdução
O objetivo do projeto é analisar a base de dados do ENEM de 2013 e buscar algumas respostas para hiósteses estabelecidas pela equipe.

## 🚨 Instruções
Por se tratar de um dataset muito pesado, o usuário deve baixar os dados no link a seguir: https://download.inep.gov.br/microdados/microdados_enem_2013.zip
O dataset deve ser armazenado no mesmo diretório que o arquivo de execução do programa para que funcione corretamente.

## 📖 Estrutura do projeto:
- **Dicionário_Microdados_Enem_2013.xlsx**: Dicionário do significado de cada coluna do dataset original.
- **PROJETO_PANDAS.ipynb**: código com as análises.

## 💡 Hipósteses
1.  Qual a relação entre ter carro e faltar à prova?
2.  A nacionalidade influencia na nota (língua diferente)?
3.  Qual o perfil de quem teve a redação anulada por ferir direitos humanos?
4.  Há diferença entre as notas das matérias entre cada gênero, raça e classe?

## 🛠 Ferramentas Utilizadas
- **Pandas**: Para manipulação de dados e análise exploratória.

## 📍 Conclusão

1.  Embora o carro possa facilitar o acesso das pessoas aos estudos, possivelmente a análise não seja 100% confiável quando relacionada com a renda dos participantes.
2.  Estrangeiros tiraram notas maiores que os brasileiros, de forma geral. Isso pode estar atrelado à hipótese que estrangeiros têm uma preocupação maior com o estudo da língua portuguesa do que os próprios brasileiros, que se sentem mais à vontade por se tratar do seu idioma nativo.
3.  Mulheres cometeram 55% das infrações enquanto homens 45%. Dado proporcional a participação das mulheres no enem que foi de 58,34%. No quesito cor/raça, pessoas pardas anularam 43%, seguida por pessoas brancas 38% e pretas 15%. Mais uma vez proporcional à participação de pessoas pardas na prova (43,41% de pessoas pardas). 
4.  Infelizmente, mulheres tiveram notas menores que homens em todas as áreas da prova objetiva. 
A maior diferença se deu em matemática, com 40 pontos de diferença em média e a menor em Linguagem e códigos, com apenas 2 pontos de diferença.
Porém apresentaram desempenho superior na redação.
